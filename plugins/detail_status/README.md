# Detail status styling (Lampa)

Подключаемый JS-плагин для страницы фильма/сериала. Изменяет только подпись и оформление статуса в верхней части подробной карточки. Исходные файлы Lampa не меняются.

## Подключение

Добавьте ссылку на JavaScript-файл в разделе плагинов Lampa:

```text
https://cdn.jsdelivr.net/gh/ivzaislu/lampa-source@9e4c4acec6a656c8cb595c7efd9cdf0704324b55/plugins/detail_status/detail_status.js
```

Удалите прежнюю ссылку `raw.githubusercontent.com` из списка плагинов, добавьте ссылку jsDelivr выше, затем обновите страницу Lampa и откройте подробную карточку фильма или сериала.

**Почему не raw.githubusercontent.com:** GitHub отдаёт raw JavaScript с MIME-типом `text/plain`, из-за чего браузер может блокировать выполнение скрипта. jsDelivr предназначен для подключения JS-файлов из GitHub.

Ссылка выше привязана к **конкретному коммиту** для надёжного разрешения ветки с `/` в имени и стабильности версии. После следующих изменений плагина потребуется обновить ссылку на новую версию.

## Статусы

| Исходный статус | Надпись | Рамка |
|---|---|---|
| Returning Series / Ongoing | Идёт | Зелёная |
| Ended | Завершён | Красная |
| Canceled / Cancelled | Отменён | Красная |
| In Production / Post Production | В производстве / Постпроизводство | Жёлтая |
| Planned / Pilot / Rumored | Запланирован / Пилот / По слухам | Серая |
| Released | Выпущен | Зелёная |

Незнакомые статусы остаются без изменений. Плагин не меняет настройки языка приложения и не вмешивается в навигацию или кнопки управления.

## Технически

- Один JS-файл без внешних зависимостей; подходит для подключения напрямую по URL.
- Использует событие `Lampa.Listener.follow('full', ...)` при `type === 'complite'`.
- Стили внедряются динамически и применяются только к `.full-start__status` с классом плагина.
- Защита от повторной инициализации.
- Для локальной сборки структура соответствует механизму сборки `plugins/<name>/<name>.js`.
