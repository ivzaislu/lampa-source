# Detail status styling (Lampa)

Подключаемый JS-плагин для страницы фильма/сериала. Улучшает статусы фильмов и отображение горизонтального ряда эпизодов. Исходные файлы Lampa не меняются.

## Подключение

Добавьте ссылку на JavaScript-файл в разделе плагинов Lampa:

```text
https://cdn.jsdelivr.net/gh/ivzaislu/lampa-source@853e38bcaf6415256c5f239ffe3c544c302647e2/plugins/detail_status/detail_status.js
```

Удалите прежнюю ссылку `raw.githubusercontent.com` из списка плагинов, добавьте ссылку jsDelivr выше, затем обновите страницу Lampa и откройте подробную карточку фильма или сериала.

**Почему не raw.githubusercontent.com:** GitHub отдаёт raw JavaScript с MIME-типом `text/plain`, из-за чего браузер может блокировать выполнение скрипта. jsDelivr предназначен для подключения JS-файлов из GitHub.

Ссылка выше привязана к **конкретному коммиту** для надёжного разрешения ветки с `/` в имени и стабильности версии. После следующих изменений плагина потребуется обновить ссылку на новую версию.

## Статусы

| Исходный статус | Надпись | Рамка |
|---|---|---|
| Returning Series / Ongoing, показ текущего сезона ещё продолжается | Идёт | Зелёная |
| Сезон полностью вышел, но сериал не завершён | Продолжение следует… | Жёлтая |
| Есть дата следующей серии | Скоро новая серия | Зелёная |
| Есть дата следующего сезона | Скоро новый сезон | Жёлтая |
| Ended | Завершён | Красная |
| Canceled / Cancelled | Отменён | Красная |
| In Production / Post Production | В производстве / Постпроизводство | Жёлтая |
| Planned / Pilot / Rumored | Запланирован / Пилот / По слухам | Серая |
| Released | Выпущен | Зелёная |

Для определения завершённого сезона плагин сверяет номер последнего вышедшего эпизода с числом серий сезона или проверяет список эпизодов целиком. Если в данных нет достаточно надёжных сведений, остаётся «Идёт». Точные даты выхода не выдумываются. Если имеется информация о следующей серии, она имеет приоритет.

Плагин изменяет только исходный бейдж статуса и **не меняет бейдж качества** (`TS`, `CAM`, `WEB-DL` и т. п.) даже при совпадении CSS-классов. Незнакомые статусы остаются без изменений. Плагин не меняет настройки языка приложения и не вмешивается в навигацию или кнопки управления.

## Оформление блока «Сезон»

- Серии отображаются в **компактных** горизонтальных карточках: ширина уменьшена с 17,5 до 13,25 em, пропорции кадра 16:9 сохранены.
- Название и номер серии — в одной строке, дата и доступность — во второй; лишние отступы и большие подписи убраны.
- Для вышедших серий добавляется подпись «Доступна». Для будущих — календарь с датой внутри превью, подпись «Премьера» и короткий статус «Скоро». Если дата неизвестна, показываем «Дата уточняется».
- Кнопка «Ещё» называется **«Все серии»** и теперь совпадает с карточками серий по **ширине и высоте**; она остаётся первой в ряду, сохраняя открытие прежнего списка. Это сознательное решение: перемещение первого элемента нарушает индексы и фокус TV-навигации.
- Заголовок «Сезон 2» оформлен как обычный заголовок раздела в Lampa, а номер **02** выделен отдельной неброской голубой плашкой. Справа продолжается тонкая линия-разделитель. Для других названий (не совпадающих с «Сезон N» / «Season N») сохраняется исходная надпись.
- Есть мягкое белое выделение при фокусе и отдельные стили для мобильных устройств. Уважается `prefers-reduced-motion`.
- Редизайн применяется только к ряду эпизодов внутри полной карточки, включая лениво подгружаемые элементы. Полный список сезонов и остальные ряды не затрагиваются.
- Оригинальные обработчики Lampa для открытия серий, отметки просмотра, навигации и прокрутки сохраняются.

## Карточки актёров

- Актёрские и режиссёрские ряды оформляются компактными горизонтальными плитками с фото, именем и ролью, в тех же приглушённых оттенках, что и блок серий.
- По умолчанию ширина плитки 17em, фотография 5.3em; для узких экранов размеры уменьшаются.
- На телевизоре остаются стандартные `selector`, `focus` и обработчики перехода к странице актёра. Контраст фокуса зафиксирован тёмной заливкой и белой рамкой. Подгружаемые по прокрутке карточки получают тот же дизайн автоматически.
- Визуальный CI отдельно проверяет ширину и высоту плиток актёров, совпадение габаритов кнопки «Все серии» с карточкой эпизода и отсутствие переполнения мобильного экрана.

## Технически

- Один JS-файл без внешних зависимостей; подходит для подключения напрямую по URL.
- Использует событие `Lampa.Listener.follow('full', ...)` при `type === 'complite'`.
- Стили внедряются динамически и применяются только к `.full-start__status` с классом плагина.
- Защита от повторной инициализации.
- CI в GitHub Actions: отдельные задания для тестов плагина, общего набора тестов приложения и браузерного скриншот-тестирования (TV / desktop / mobile).
- Регрессионные проверки: `spec/detail_status_plugin.spec.js` и `spec/detail_episodes_plugin.spec.js` (запуск: `npm test -- spec/detail_status_plugin.spec.js spec/detail_episodes_plugin.spec.js`).
- Для локальной сборки структура соответствует механизму сборки `plugins/<name>/<name>.js`.
